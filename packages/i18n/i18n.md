# ~@/i18n

Internationalization module for the Vega project built on top of Lingui. It handles message extraction, compilation, and runtime locale switching with support for multiple languages including pseudo-localization for testing.

## Using in Components

```tsx
// Import i18n utilities from the global module
import { t, Trans } from '~@/i18n/macro';
import { i18n } from '@lingui/core';

// Use Trans component for JSX content
<Trans>Welcome to Vega</Trans>

// Use t macro for string interpolation
const welcomeMessage = t`Welcome, ${userName}!`;

// Access the i18n instance for programmatic use
const currentLocale = i18n.locale;
```

## Import Patterns

Always use the global i18n module instead of importing Lingui packages directly:

```ts
// ✅ Correct - Use global module
import { I18nProvider } from '~@/i18n';
import { t, Trans } from '~@/i18n/macro';

// ❌ Incorrect - Direct Lingui imports are banned
import { Trans } from '@lingui/react';
import { t } from '@lingui/core/macro';
```

## Translation Macros

### `t` - String translation

```typescript
import { t } from "~@/i18n/macro";

// Simple translation
const message = t`Hello World`;

// With variables
const greeting = t`Hello ${userName}`;

// With expressions
const count = t`You have ${unreadCount} unread messages`;
```

### `msg` - Define messages

```typescript
import { msg } from "~@/i18n/macro";

// Define messages for use elsewhere
const messages = {
  welcome: msg`Welcome to Vega`,
  error: msg`An error occurred`,
  success: msg`Operation successful`
};
```

## React Components

### `Trans` - Component for JSX

```tsx
import { Trans } from "~@/i18n/macro";

function MyComponent() {
  return (
    <div>
      <Trans>Welcome to our platform</Trans>

      {/* With nested components */}
      <Trans>
        <strong>Note:</strong> Please enter your credentials
      </Trans>

      {/* With variables */}
      <Trans>Hello {userName}, you have {count} messages</Trans>
    </div>
  );
}
```

### `Plural` - Pluralization

```tsx
import { Plural } from "~@/i18n/macro";

function MessageCount({ count }: { count: number }) {
  return (
    <Plural
      value={count}
      zero="No messages"
      one="# message"
      other="# messages"
    />
  );
}
```

### `Select` - Conditional selection

```tsx
import { Select } from "~@/i18n/macro";

function UserStatus({ status }: { status: string }) {
  return (
    <Select
      value={status}
      online="User is online"
      offline="User is offline"
      away="User is away"
      other="Unknown status"
    />
  );
}
```

### `useLingui` Hook

```tsx
import { useLingui } from "~@/i18n/macro";

function MyComponent() {
  const { i18n } = useLingui();

  // Change language
  const changeLanguage = (lang: Language) => {
    i18n.load(lang, messages[lang]);
    i18n.activate(lang);
  };

  // Format date
  const formattedDate = i18n.date(new Date());

  // Format number
  const formattedNumber = i18n.number(1234.56);

  return (
    <div>
      <p>{formattedDate}</p>
      <p>{formattedNumber}</p>
    </div>
  );
}
```

## Translation Management

### Workflow

1. **Write code with translation macros**
2. **Extract messages** → generates `.po` files
3. **Translate** → edit `.po` files
4. **Compile** → generates optimized `.ts` files

### Translation Process

1. **Extraction**: Runs automatically to find all messages marked with macros
2. **Translation**: The `.po` files in `locales/` will contain the messages to translate:
   ```po
   #: packages/views/login/SignIn.tsx:17
   msgid "Email address"
   msgstr "Dirección de correo electrónico"
   ```
3. **Compilation**: Runs automatically to generate optimized TypeScript files

## Available Scripts

```bash
# Extract messages from source code
pnpm i18n:extract

# Watch for changes and extract automatically
pnpm i18n:watch

# Compile translations to TypeScript
pnpm i18n:compile
```

## Supported Languages

Available languages are defined in the `Language` enum:

```typescript
import { Language } from "~@/i18n";
```

### Dynamic Language Switching

```typescript
import { i18n } from "@lingui/core";
import { Language } from "~@/i18n";

// Load and activate a language
async function dynamicActivateLocale(lang: Language) {
  const { messages } = await import(`~@/i18n/locales/${lang}.ts`);
  i18n.load(lang, messages);
  i18n.activate(lang);
}
```

## Best Practices

### 1. Use correct import patterns

Always use the global i18n module instead of importing Lingui packages directly:

```ts
// ✅ Correct - Use global module
import { I18nProvider } from '~@/i18n';
import { t, Trans } from '~@/i18n/macro';

// ❌ Incorrect - Direct Lingui imports are banned
import { Trans } from '@lingui/react';
import { t } from '@lingui/core/macro';
```

### 2. Always use macros for visible text

```tsx
// ❌ Wrong
<button>Submit</button>

// ✅ Correct
<button><Trans>Submit</Trans></button>
```

### 3. Avoid string concatenation

```tsx
// ❌ Wrong
const message = t`Hello` + " " + userName;

// ✅ Correct
const message = t`Hello ${userName}`;
```

### 4. Use descriptive IDs for complex messages

```tsx
// For long or important messages
<Trans id="login.welcome.message">
  Welcome back! Please enter your credentials to continue.
</Trans>
```

### 5. Keep translations up to date

- Regularly review `.po` files for untranslated messages
- Untranslated messages will appear with `msgstr ""`

## Important Notes

- **Don't edit** `.ts` files in `locales/` - they are auto-generated
- **Always translate** in `.po` files
- **Macros** are removed at build time for optimization
- **Extraction and compilation** are integrated into dev and build commands
